BACKUP

The backup has the rolls, the print history, the settings, the slicer API keys, the paired phones and the Klipper config. It does not have the password of this Printdeck or the Wi-Fi network. The backup password encrypts the file. Keep the password safe: without it, nobody can open the backup.

RESTORE

The Printdeck checks the whole file before it changes a file. Then it puts back the files of the backup, and Klipper and the Printdeck restart. The password of this Printdeck and its Wi-Fi network stay. Do not restore during a print.
