Printdeck

A Raspberry Pi 5 with a 7" touch screen next to the 3D printer. It runs Klipper, and shows and controls the print on the touch screen, on the display of the printer, and in a browser.

Download Printdeck OS Install The manual Build the hardware Source on GitHub

Before you use it

Printdeck is a personal project, for personal use. It follows the goals of one person for print software.

  • Printdeck has run on one printer only: a LulzBot TAZ Workhorse.
  • AI writes the code and the documentation. The code gets tests, and a person reads the documents. Errors can still occur.
  • Results on your printer can be different. Use Printdeck at your own risk.

Install

  1. Download printdeck.img.xz from the latest release.
  2. Write it to a USB SSD or an SD card with Raspberry Pi Imager ("Use custom").
  3. Start the Pi. The setup on the touch screen connects the Wi-Fi and finds the printer.

To update, open Machine > Software update on the touch screen. os/README.md has the details.

The Printdeck OS page has the first start, the login, the settings and the update in full.

Goal

Printdeck is a very small operating system with one purpose. The Printdeck program is one static Go binary with no runtime dependencies, on a minimal Linux system. We build it from open source projects, such as Klipper. We respect their licenses, give credit, and keep our license compatible. We are not here to take code. We reform it into something new and give it back, in the spirit of open source, with the help of AI. ARCHITECTURE.md has the plan and the rules.

Printdeck is one integrated stack. The printer firmware, the touch screen, the web screen, the slicer integration, and the iPhone and Apple Watch apps are made to work together.
