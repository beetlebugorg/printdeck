What the plugin does

The Printdeck plugin connects Cura to the Printdeck. It uses the printer of the OctoPrint connection plugin, with the same address and API key. After the setup, the plugin works by itself. A message in Cura tells you what it did.

The deck in the Printdeck tab of Cura

  • The print button says Print to Printdeck. After a send, Cura opens the Printdeck tab.
  • The Printdeck tab shows the touch screen of the deck, live. You click it as you tap the touch screen.
  • When the roll in the deck changes, Cura changes to the material of the roll.
  • After a slice, Cura warns you when the roll is too short for the model.
  • During a print, the Preview of Cura shows the layer that prints.
  • The Print on a part tool prints new models on a part that is printed already.

The plugin works with Cura 4.13 (Cura LulzBot Edition) and later. The pictures in this booklet show Cura 5.

Setup
3

Install the plugin

From the release

  1. 1Open the releases of the Printdeck: https://github.com/beetlebugorg/printdeck/releases.
  2. 2Download the file Printdeck.curapackage from the latest release.
  3. 3Drag the file onto the Cura window. Cura installs the plugin.
  4. 4Close Cura, and start it again.

From the repository

  1. 1In Cura, select Help > Show Configuration Folder.
  2. 2Copy the folder slicer/cura-plugin/Printdeck of the Printdeck repository into the plugins folder of the configuration folder.
  3. 3Close Cura, and start it again.

To make the package yourself, run slicer/cura-plugin/package.sh. It writes Printdeck.curapackage.

Setup
4

Connect the Printdeck

The plugin uses the printer of the OctoPrint connection plugin. The deck answers the OctoPrint API, so Cura sees it as an OctoPrint printer named Printdeck. Install the OctoPrint connection plugin first.

  1. 1In Cura, open the Marketplace. Install OctoPrint Connection, and restart Cura.
  2. 2Select Preferences > Configure Cura > Printers. Select your printer, and click Connect OctoPrint.
  3. 3Select Printdeck in the list. If the list does not show it, click Add, and type the address printdeck.local.
  4. 4Click Request to get the API key.
  5. 5The touch screen asks "Allow Cura to use the Printdeck?". Tap Allow.
  6. 6Click Connect, and close the preferences.

When Cura connects, the plugin shows the filament in the printer, for example: "Connected to the Printdeck. PLA is in the printer."

The system page of the deck also shows the API key for slicers: http://printdeck.local/system.

Setup

Send a print

The print button

  1. 1Slice the model as usual.
  2. 2Click Print to Printdeck. Cura sends the file to the deck.
  3. 3Cura opens the Printdeck tab. The tab shows the deck as the print starts.

The OctoPrint connection starts the print after the upload when its option "Automatically start print job after uploading" is on. Each file that Cura sends has the material of Cura in its header.

The Printdeck tab

The Printdeck tab is next to Monitor. It shows the screens of the deck, live. Click a key in the tab as you tap it on the touch screen.

1234567
  1. 1Printdeck. The tab of the plugin, next to Monitor.
  2. 2Printer display. The temperatures, the fan, and the progress of the print.
  3. 3Pause. Pauses the print.
  4. 4Tune. Opens the speed, the flow, the Z offset, the fan and the heaters.
  5. 5Cancel. Cancels the print. The deck asks first.
  6. 6The file. The name of the file, the layer, and the time left.
  7. 7The layer. The model up to the layer that prints now.

Printing
8

The roll and the material

The deck keeps a list of your rolls of filament: Filament on the touch screen. The plugin reads the roll in the printer every 10 seconds.

Cura follows the roll

When the roll in the deck changes, Cura changes to the material of the roll. A message tells you, for example: "The Printdeck has Black (PLA). Cura now prints with Generic PLA." When Cura has no profile for that material on this printer, the message tells you, and Cura keeps its material.

A short roll

After a slice, Cura compares the grams of the model with the grams left on the roll. When the roll is too short, a message stays until you close it: "The model needs 120 g of filament. Black has 80 g left."

A file for another material

Cura writes its material into the header of each file that it sends. Before the deck prints a file for another material, the touch screen asks first, for example: "The file is for Black ABS. White (PLA) is in the printer." Tap Print anyway to print the file. To print with the correct material, change the roll first.

Printing
9

Follow the print

During a print of the file that Cura has open, the Preview shows the layer that prints. The Preview goes to the next layer when the deck starts it. Between two layers, you can look at other layers.

The messages of the plugin

After a restart of Cura

  1. 1Start Cura during a print. Cura connects to the deck, and shows the message "The Printdeck prints <file>. Cura can show it in the Preview, at the layer that prints."
  2. 2Click Show the print. Cura downloads the file from the deck, and opens it in the Preview.
  3. 3The Preview follows the layer that prints.

Cura shows no print time for a G-code file. The Printdeck tab shows the time left. When the print ends, Cura shows a message.

Print on a part

The Print on a part tool prints new models on a part that is printed already, for example a logo in another color on a lid. The part goes into a pocket that the deck prints on the bed, so its place is exact. The deck then checks the height of the part with a paper test.

The tool

1234567
  1. 1Print on a part. The tool, at the bottom of the left toolbar of Prepare.
  2. 2Set as base. The selected model is the base: the part that is printed already. Cura does not print it, and adds the pocket.
  3. 3Place on the base. Puts the selected model on the top of the base.
  4. 4The pocket is on the bed. For the next color. The file then has no pocket.
  5. 5Clearance and Wall. The gap around the part, and the height of the pocket wall, in mm.
  6. 6Message on the deck. The text of the pause on the touch screen.
  7. 7Clear the base. The base is a usual model again, and Cura removes the pocket.

The tool also has Place as in the files, and the fields of the text on the base. The next page explains them.

Print on a part
11

Prepare the job

  1. 1Open the part and the new models in Cura. Lay the part on the bed with its face for the new models up.
  2. 2Keep the part away from the front and the left edge. The print primes the nozzle there.
  3. 3Select the part, and click Set as base. Cura adds the pocket: a low wall around the part, with open corners.
  4. 4Select a new model, and click Place on the base. The model goes to the top of the part, and stays at that height.
  5. 5Move the model on the face as usual. To print into a pocket of the part, lower the model with the Z of the Move tool.

A part in its pocket

Files from one assembly

When the part and the new models come from one assembly, their files share one frame. Select the new models, and click Place as in the files. The models go to their exact place on the part, also after you turned the part.

Lettering

Type the text, its size, and its height over the face (Raised). Then click Add text. The text goes on the top of the part, at its middle. Move and turn it as usual.

While a part is the base, the tool turns off "Ensure models are kept apart" in the preferences of Cura. That setting pushes the pocket away from the new models. Click Clear the base to turn it on again.

Print on a part
12

At the printer

  1. 1Click Print to Printdeck. The deck prints the pocket on the bed.
  2. 2The nozzle lifts, and the print pauses. The touch screen shows the message of the pause.
  3. 3Put the part in the pocket.
  4. 4For another color, change the filament now.
  5. 5Tap Check the height. The nozzle goes over the part.
  6. 6Put a sheet of paper under the nozzle. Lower the nozzle until the paper drags a little, then tap Accept.
  7. 7Tap Resume. The new models print on the part.

The height check sets the height of the new models on the real part. After the check, the screen shows the difference from the file, for example +0.12 mm. If you tap Resume with no height check, the deck asks first.

The next color

Keep the part in its pocket. In the tool, check The pocket is on the bed, and send the next file. That file has no pocket. It homes Z up first, does not probe the bed, and purges beside the pocket.

The pause and the height check need the deck bundle with [printdeck_pause]: v0.2.0-beta.1-9 or later.

13

Test print: the cube

The files are in slicer/test-prints/onpart/ of the repository. The test is a 20 mm cube, then a cross on its top in another color. The cross is 1 mm high, with arms of 14 x 3 mm.

Job 1: the cube

  1. 1Open cube.stl in Cura, and print it (about 16 minutes).
  2. 2Take the cube off the bed.

Job 2: the holder and the cross

  1. 1Clear the build plate. Open cube.stl and cross.stl.
  2. 2Select the cube, and click Set as base. Cura adds the holder (the pocket) around the cube, and does not print the cube.
  3. 3Select the cross, and click Place as in the files. The cross goes on the top of the cube.
  4. 4Print. The deck prints the holder, then lifts the nozzle and pauses.
  5. 5Put the cube in the holder.
  6. 6Change the filament to the second color.
  7. 7Tap Check the height, and do the paper test on the top of the cube.
  8. 8Tap Resume. The deck prints the cross.

What to look at

  • XY: the cross is at the center of the top. Measure the 3 mm from each arm end to the edge of the cube.
  • Z: the first layer of the cross sticks to the cube. It is not squashed, and it is not in the air.
  • The purge after the filament change does not go on the cube.
