17Look after the printer

Machine has the information of the printer, the history of the prints, the macros, the console and the settings.

18Update the Printdeck

The deck checks for a new version once a day. Machine then shows Software update in orange.

The deck installs only a signed version. If the new system fails to start, the deck goes back to the old one.

  1. Open Machine, then Software update.
  2. Read the notes of the new version, then tap Install. The deck installs only when no print runs.
  3. Wait for the download. The deck restarts into the new version.

19Back up your data

A backup is one file with your rolls, history, settings, API keys, paired phones and Klipper config. Make a backup before you change the SD card.

Keep the backup password safe. Without it, no one can restore the backup.

The backup excludes the deck password and the Wi-Fi network.

  1. Open http://printdeck.local/system in a browser, and log in with the password of the deck.
  2. Under Backup, type a backup password of 8 characters or more, two times. To add the G-code files, select Include the G-code files.
  3. Click Download the backup. The browser saves a file with the name printdeck-backup-NAME-DATE.pdbk.
  4. To restore, open the same page when no print runs. Under Restore, type the backup password, choose the file, then click Restore.
  5. Klipper and the Printdeck restart. A wrong password or a damaged file changes no data.

20Try the deck with a simulated printer

The simulated printer heats, homes, probes and prints in real time, and no motor moves. Use it to learn the deck or to test a file.

Your printer.cfg stays as printer.cfg.real until you tap Real printer.

  1. Open Machine, then Simulated printer. The setup screen also has this key.
  2. Tap the printer to simulate, then Simulate. Klipper restarts with the simulated printer.
  3. Print as on a real printer: send a file from the slicer, or tap Print a file.
  4. To stop the simulation, open Machine, then Simulated printer, and tap Real printer, then Go back. Klipper restarts with your printer.cfg.

The deck changes the printer only when no print runs.
