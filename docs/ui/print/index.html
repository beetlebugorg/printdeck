07Send a file from the slicer

The deck uses the OctoPrint API, so slicers can send files and start prints.

Cura: add the deck with the OctoPrint Connection plugin. The deck asks "Allow Cura to use the Printdeck?". Tap Allow.

OrcaSlicer or PrusaSlicer: add a printer of the type OctoPrint, with the address http://printdeck.local and the API key of the system page.

The webcam is the camera with the use Apps: http://printdeck.local/webcam/stream and /webcam/snapshot, with the API key. Add camera=2 for the second camera, w=320 for smaller pictures, or fps=2 for fewer frames. With no camera, the webcam shows the deck screen.

08Start a print

The newest file is at the top. Each file shows the print time, the filament and the layer height from the slicer. Cura, PrusaSlicer, OrcaSlicer and Bambu Studio write this data.

  1. Tap Print a file on the idle screen.
  2. Tap the file. Check the print time, the filament and the temperatures.
  3. Tap Print, then Print again.

09Watch the print

The deck shows a screen for each phase of the print.

  1. Watch the first layer. Use − and + to set the nozzle height.
  2. Tap Save to keep the Z offset for the next prints.
  3. Use Tune to change the speed, the flow or the fan.
  4. When the print is done, wait for the bed to cool. Then remove the part.

10Print in two colors

The Colors tool of the Cura plugin gives a model a roll of another color. The print pauses at the first layer of that model.

  1. In Cura, put the letters on the part. Select the letters, open the Colors tool, and tap their roll.
  2. Print. At the first layer of the letters, the printer parks and the deck shows Change filament in orange.
  3. Tap Change filament. Unload, load the roll of the letters, and tap Done.
  4. Pull the ooze off the nozzle with tweezers, then tap Resume.

11Look around during a print

During a print, the other screens are read only. The deck goes back to the print after 2 minutes with no touch.

Tap Menu to open the other screens. Tap the print bar at the bottom to go back to the print.

12Make a time lapse

The deck camera captures a picture at each layer change. At the end of the print, the deck makes a video.

For each picture, the printer retracts, lifts the nozzle and moves the head to the left side. The bed stays where it is, under the camera. On the TAZ Workhorse the nozzle goes to Z 10 mm or more, over the bed washers. Each picture adds a few seconds.

  1. Aim the camera: Settings, then Camera.
  2. Open Settings, then Time lapse.
  3. Tap Time lapse to turn it on.
  4. With two cameras, open Settings, then Cameras. Tap a camera, and check Time lapse or Pictures.
  5. Tap First layer for a picture of the first layer, or a picture and a pause. At a pause, check the layer, then tap Resume.
  6. Print. After the first layer, the deck shows its picture.
  7. At the end of the print, open http://printdeck.local/system in a browser. The Time lapse part has the video. Click its name to download it.

Cura, PrusaSlicer and OrcaSlicer write the layer comments that the time lapse needs.

Park for the frames is on by default. Off keeps the toolhead in the pictures, with no stops.

The video is a .mov file. The deck keeps the last 3 videos. A backup excludes the videos.

From the manual for a tall display. The deck draws every picture.
