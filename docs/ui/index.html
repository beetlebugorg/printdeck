The deck UI

The screens of the deck

Every screen of the touch screen, for a display that is mounted tall or wide.

On this page

  2. The chapters
  3. The manuals and the booklets

Every screen of the deck, with numbered callouts. The pod uses the tall layout. Each page has a switch to the wide layout.

The screens

  • Each screen shows the printer display at the top.
  • The print screen shows the model in 3D, the layer, the roll and the layer times. It can pause, resume, tune and cancel.
  • Toolhead homes and moves the head, and turns off the motors.
  • Filament has the guided filament change and your rolls of filament.
  • Machine has the calibrations, the firmware, the console, the settings and the history.
  • Machine > Settings has the camera, the push messages and the time lapse.
  • A display that is mounted wide gets a machine panel layout.

slicer/cura-plugin/ is the Printdeck plugin for Cura. slicer/ also has a Cura post-processing script for the speed of each move.

The manuals and the booklets

The manual shows each screen of the deck with numbered callouts.

  • The manual: on the web, or the booklet docs/manual/printdeck-manual.pdf.
  • The manual for a wide display: on the web, or docs/manual/wide/printdeck-manual.pdf.
  • The Cura plugin: on the web, or docs/cura/printdeck-cura.pdf.

To print a booklet yourself, print the -print.pdf file on both sides of letter paper (flip on the short edge). Fold the stack, and staple it in the fold.

After a change to the UI, run docs/manual/build.sh. After a change to the Cura plugin, run docs/cura/build.sh. After a change to a README or a manual, run docs/build.py.

Printdeck is free software (AGPL-3.0). docs/build.py writes this site from the files of the repository.
