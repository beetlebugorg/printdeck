The reference printer

The printer that the Klipper port is tested against.

The printer of the Printdeck: a LulzBot TAZ Workhorse with an UltiMachine RAMBo board, on Klipper.

FileWhat it is
printer.cfgThe Klipper configuration. Put it on the PRINTDECK partition to use it (see os/README.md).
firmware.configThe Klipper firmware configuration of the RAMBo (make menuconfig in Klipper).

The Go port of Klipper's host is tested against this printer: tools/klipper-reference runs the real Klipper host in batch mode with these two files.

Printdeck is free software (AGPL-3.0). docs/build.py writes this site from the files of the repository.
