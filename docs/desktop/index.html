Desktop app and simulator

The Printdeck for a computer, and a simulated TAZ Workhorse in 3D.

On this page
  1. printdeck app
  2. The window
  3. The meshes of the 3D window

desktop/ is the Printdeck for a computer. It is a Qt 6 window around printdeck app, which runs the Klipper host and the deck UI for a printer on USB. Cura finds it at the same address after each start, as it finds a Printdeck. The keyboard of the computer types on the deck.

printdeck app -sim runs the deck with a simulated printer: a TAZ Workhorse on a simulated printer board. The board has the endstops, the probe and the display of the printer, at the places in printer.cfg. With -sim, a second window shows the printer in 3D:

  • The model of the Workhorse comes from the CAD files of LulzBot. The axes and the belts move with the steps of the board, and the filament goes down where the nozzle is.
  • The Printdeck mount from lulzbot/ is on the printer, and its screen shows the deck UI.
  • The display of the printer shows the dots that the Klipper host sends to it.
  • The left button turns the view, the right button pans it, and the wheel zooms. T makes the tool head see-through.

To build it, you need Go, CMake, Ninja, and Qt 6.5 or later with Qt Quick 3D:

B=~/.cache/printdeck/desktop
(cd deck && go build -o $B/printdeck ./cmd/printdeck)
cmake -S desktop -B $B -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja -C $B
$B/Printdeck -sim

desktop/film/ makes a short film of the Printdeck with the 3D window. desktop/film/film.sh tells how.

printdeck app

The window starts printdeck app and shows its remote screen. The app runs the Klipper host in its own process, as the klipper service does on the deck, and serves the screen and the API for slicers on 127.0.0.1:7351, so Cura finds it again after each start. Its flags, from deck/cmd/printdeck/app.go:

FlagDefaultWhat it does
-dirthe folder of the app (default: the configuration folder of the user)
-addr127.0.0.1:7351the address of the web server
-parentoffend when the input closes (the window of the app started the program)
-simoffa simulated printer: the TAZ Workhorse on the simulated board, in its own folder

The folder of the app has gcodes/, models/, klipper/printer.cfg, klipper/printdeck.cfg (the app writes it at each start), logs/klippy.log and the API socket klippy.sock. A new folder gets a printer.cfg with only the include of the Printdeck sections: put the configuration of your printer above it. With -sim, a new folder gets the simulated TAZ Workhorse (deck/internal/printer/sim/taz-workhorse.cfg).

The window

The window program (desktop/) reads these environment variables:

VariableWhat it does
PRINTDECKThe path of the printdeck program. Without it, the window starts the program next to the window program.
PRINTDECK_ATTACHA file with the first line of the output of a printdeck app that runs already. The window connects to that app and starts no app.
PRINTDECK_FILMWith -sim: the 3D window shows the film of desktop/film/, and records it to this file when the file with .go added exists.
PRINTDECK_SHOTA PNG file: the window writes a picture of the windows after PRINTDECK_SHOT_SECONDS (8), and ends. With PRINTDECK_SHOT_FRAMES=N and -sim, it first writes N pictures of the 3D window, 10 a second.

The deck UI in the window is drawn by the QML files of the Cura plugin (slicer/cura-plugin/Printdeck/qml), so the two stay the same.

The meshes of the 3D window

The printer meshes come from the CAD of the LulzBot TAZ Workhorse ("Redgum"): https://gitlab.com/lulzbot3d/printers/redgum

The CAD is by LulzBot. It has the licenses "GPLv3 or later and/or CC BY-SA 4.0". These meshes have the same licenses.

cad/export.py makes the meshes from the FreeCAD files of the CAD. The file has the steps.

The deck_*.bin meshes are the Printdeck mount of this repository (lulzbot/). cad/deck.py makes them from the meshes of lulzbot/make.sh. They have the license of this repository.

Printdeck is free software (AGPL-3.0). docs/build.py writes this site from the files of the repository.
