Connect to Wi-Fi

At the first start, the deck makes its password and opens the setup.

  1. 1Switch on the Printdeck. The setup opens.
  1. 2Tap your Wi-Fi network, then type its password.
  1. 3Wait until the deck is connected, then tap Next.
  1. 4Write down the address and the password, then tap Finish.
Set up
3

The setup: step 1

  1. 1Networks. The Wi-Fi networks near the deck, with the signal. A lock shows a network with a password. Tap a network, then type its password.
  2. 2Scan. Looks for the networks again. The list also scans by itself.
  3. 3Hidden. For a network that does not show its name: type the name and the password.
  4. 4Next. Goes to the summary when the deck is connected.
Set up
4

The setup: step 2

  1. 1Address. The address of the deck on your network. Open it in a browser for the web pages.
  2. 2Password. The password of the web pages. To see it again, open Machine > Wi-Fi and help.
  3. 3Finish. Closes the setup. The deck does not open it again.

You can also set the Wi-Fi before the first start: put the SD card in a computer, and fill in printdeck.txt on the PRINTDECK partition.

Choose your printer

A new Printdeck has no printer config. The deck then shows the printer setup.

  1. 1Connect the printer to the Printdeck with a USB cable, and switch the printer on.
  1. 2Wait until the deck finds the board. Tap Search again if it does not show.
  1. 3Tap Choose printer. The printers of the brand of your board are at the top.
  1. 4Tap your printer, then Use. Klipper restarts with its config.

Install the Klipper firmware

The board of the printer must run the Klipper firmware of this Printdeck. The deck writes it through the USB cable.

  1. 1Open Machine, then Maintenance, then tap Firmware. A new board shows Install Klipper firmware on the setup screen.
  1. 2Tap Write. Do not switch off the printer until the deck shows the result.
  1. 3Tap OK. Klipper restarts and connects to the board.
Set up
9

The firmware flash

  1. 1Step. Starting the bootloader, Writing, then Checking.
  2. 2Progress. The part of the firmware that is done.

The deck stops Klipper, resets the board into its bootloader, writes the firmware, and reads it back to check it. Then Klipper starts again. The setup screen and the Klipper error screen also show this key when the board has no Klipper firmware or old firmware. Printdeck can flash boards with an atmega2560 and an STK500v2 bootloader now, for example the RAMBo and RAMPS boards.

The deck

Printdeck is a touch screen and print server for Klipper printers. It runs Klipper. It shows the print, and it controls the printer.

When the printer does not print, the deck shows the idle screen. The largest key is the action that you need most: Print a file.

The keys are the keys of a machine. A key with an LED has two states, and its LED is lit while it is on: the page that is open, the material in the printer, Preheat. A key with no LED does an action: an orange ring shows that it took the tap.

The deck shows the display of the printer at the top of each screen. The keys of the pages are at the bottom of the idle screen. Each page has its title and Back at the top, and its actions at the bottom.

11

The idle screen

  1. 1Nozzle. The nozzle now, and its target under it while the heater is on. The icon is filled while the heater is on, and waves rise while it heats. Tap it to set the temperature.
  2. 2Bed. The same for the bed.
  3. 3Fan. The part cooling fan. Its blades turn at its speed.
  4. 4Status. The position of the head, the state of the printer with the loaded filament, and the clock. This is the status screen of the display of the printer: the same picture on both screens.
  5. 5Print a file. Opens the files. See Files.
  6. 6Preheat. Heats the nozzle and the bed for the loaded filament. Its LED is lit while the heaters hold those temperatures: tap it again to turn them off.
  7. 7Cool down. Turns off both heaters.

The display of the printer

When the printer has a display, the deck draws it. The display shows the status screen, the same picture as the idle screen of the deck.

Turn or click the knob to open the menu. The menu has the same pages and keys as the touch screen: the knob moves the cursor, and a click taps the key. The touch screen shows the cursor with an orange ring. The top item goes back: Status on the home menu, Back on a page. A long click also goes back. With no turn for 20 seconds, the display shows the status screen again.

While an action runs, the display shows an animation.

14

The deck in a browser

Open http://printdeck.local in a browser on the same network, and log in with the password of the deck. The browser shows the same screens as the touch screen, sharp at the pixel density of the phone. Each browser has its own screens, so a phone can show the files while the deck shows the print.

On a phone, use Add to Home Screen: the deck then opens as an app, with no browser bars.

The page http://printdeck.local/system shows the version, the services, the logs and the API key for slicers. It also installs an update: choose the update file, then Install. The deck writes the other system slot and restarts into it. If the new system does not start, the deck goes back to the old one.

The same page makes a backup of your data and restores it. See Back up your data.

Send a file from the slicer

The deck answers the OctoPrint API that slicers use to send files and to start prints.

In Cura, add the deck with the OctoPrint Connection plugin. The deck asks "Allow Cura to use the Printdeck?". Tap Allow.

In OrcaSlicer or PrusaSlicer, add a printer of the type OctoPrint with the address http://printdeck.local, and the API key of the system page.

The webcam of the OctoPrint API is the camera of the deck (Settings, then Camera): http://printdeck.local/webcam/stream and /webcam/snapshot, with the API key. The parameter w gives smaller pictures (for example w=320), and fps fewer frames a second (for example fps=2). With no camera, the webcam is the screen of the deck.

  1. 3Tap Print, then Print again.

Watch the print

During a print, the deck shows the screen of the phase of the print. The deck knows the phase from the printer and from the G-code of the file.

  1. 1Watch the first layer. Use − and + to set the height of the nozzle while it prints.
  1. 2Tap Save to keep the Z offset for the next prints.
  1. 3Use Tune to change the speed, the flow or the fan while the print runs.
  1. 4When the print is done, wait for the bed to cool, then take the part off.

Print in two colors

The Colors tool of the Cura plugin gives a model the roll of another color, for example raised letters on a plate. The print pauses at the first layer of that model, and the deck asks for its roll.

On Resume the deck draws a short line at the front of the bed, behind the prime line of the start. The ooze of the new filament stays on that line. The nozzle then goes back to the part with the filament pulled back a little, and pushes it forward at the first point of the layer. Each change of a print draws its line 2 mm behind the line before it.

  1. 1In Cura, put the letters on the part. Select the letters, open the Colors tool, and tap their roll.
  1. 2Print. At the first layer of the letters, the printer parks and the deck shows Change filament in orange.
  1. 3Tap Change filament. Unload, load the roll of the letters, and tap Done.
  1. 4Pull the ooze off the nozzle with tweezers, then tap Resume.

Look around during a print

The other screens are read only for the printer while it prints: the files, the filament and the rolls, the history. A tap cannot change the print by mistake. The deck goes back to the print at a pause, at a new print, and after 2 minutes with no touch.

Menu on the screens of the print shows the other screens while the print runs. The print bar at the bottom of each screen shows the print. Tap it to go back.

The iPhone and Apple Watch apps

The Printdeck app for iPhone shows the deck as its touch screen: the display of the printer, the print, the roll and the model. It can pause, resume and cancel a print, and start a file of the deck. The watch app shows the print on a blue dot-matrix display.

The apps talk to the deck on the local network. The watch reaches the deck on Wi-Fi, or through the iPhone when it is near.

  1. 1Open Printdeck on the iPhone. It finds the deck on the network. Tap Connect.
  1. 2Tap Allow on the touch screen of the deck. The app gets its own key, and sends it to the watch.
  1. 3For push messages, open Menu, then Notifications, and tap Pair for notifications. Allow the notifications.
  1. 4To add the complication, edit the watch face and choose Printdeck.
  1. 5To add a widget, touch and hold the Home Screen or the Lock Screen, tap Edit, and choose Printdeck.

Change the filament

Set the loaded filament here, so that Preheat uses its temperatures. The guided change heats the nozzle, unloads the old filament and loads the new one.

The deck keeps a list of your rolls of filament. Weigh a new roll with its reel, and the deck subtracts the weight of the empty reel. Each print subtracts the filament that it used from the roll in the printer.

  1. 1Open Filament, then tap Change filament.
  1. 2Tap the roll that goes in, or tap New roll and weigh it. The nozzle heats for its material.
  1. 3Tap Unload, and hold the filament lightly while it comes out.
  1. 4Push the new filament into the extruder until it stops, then tap Load.
  1. 5Check that clean plastic of the new color comes out, then tap Done.

Level and calibrate

Maintenance lists the calibrations that your printer has. The list comes from the config of the printer. Open it from Machine.

  1. 1Open Machine, then Maintenance.
  1. 2Tap Bed tilt or Bed mesh to probe the bed. The deck shows the action until it ends.
  1. 3Tap Probe Z offset for the paper test. Move the nozzle down until a sheet of paper drags a little, then tap Accept.
  1. 4Tap PID tune after you change a heater or a fan. A PID tune runs for about 10 minutes.
  1. 5Tap Save config to write the results. Klipper restarts.
  1. 6Tap Pressure advance test to print the tower. Then tap Pressure advance, and type the height of its sharpest corners.
Level and calibrate
49

The Maintenance page

  1. 1Bed tilt. Probes the bed, and corrects its tilt (BED_TILT_CALIBRATE). A printer with a bed mesh shows Bed mesh.
  2. 2Probe Z offset. The paper test for the height of the nozzle (PROBE_CALIBRATE).
  3. 3PID tune. Heats the nozzle to 210° and the bed to 60°, and finds the PID settings of each heater (PID_CALIBRATE). Save config then writes them.
  4. 4Nozzle change. Heats the nozzle to 250° and raises the head, to change the nozzle.
  5. 5Firmware. Writes the Klipper firmware of this Printdeck to the board of the printer. Orange text shows old firmware. See below.
  6. 6Save config. Writes the results of the calibrations into printer.cfg. Klipper restarts. Orange text shows unsaved results.
Level and calibrate
50

The Maintenance page (more)

  1. 7Pressure advance test. Prints a square tower, 30 mm high, with thin walls. The pressure advance goes up with the height: 0.005 for each mm. Measure the height where the corners are sharpest.
  2. 8Pressure advance. Type the height of the sharpest corners. The deck sets the pressure advance from it, and writes it in printer.cfg.

51

An action runs

  1. 1Action. The time since the start, a bar that moves while the action runs, and the temperatures.
  2. 2Stop the printer. Stops the printer at once, after one question. Then use Firmware restart.

While an action runs, the deck shows it on the deck and in each browser, and the other keys are off. The display of the printer shows the name of the action and a moving bar. When the action ends, a short message says that it is done. When it fails, the deck shows the error of Klipper until you tap OK.

Look after the printer
54

The Machine page

  1. 1Information. The version of Klipper, the state of the firmware of the board, the network address, and the totals.
  2. 2Maintenance. The calibrations that the printer has, the firmware, and Save config. See Maintenance.
  3. 3Macros. The macros of the printer. Tap one to run it.
  4. 4Console. The G-code terminal of Klipper. See below.
  5. 5Restart Klipper. Restarts the Klipper host, which reads printer.cfg again.
  6. 6Firmware restart. Restarts the firmware of the board, for example after a stop.

  8. 8Prints. The totals of all prints. History on that page lists each print. See below.

The rows are in groups: the printer, the history of the prints, and the deck. Drag the list up to see the rows further down.

Update the Printdeck

The deck checks for a new version once a day. Machine then shows Software update in orange.

Each version has a signature. The deck installs only a version with a valid signature of Printdeck. It writes the other system slot and restarts into it. If the new system does not start, the deck goes back to the old one.

  1. 1Open Machine, then Software update.
  1. 2Read the notes of the new version, then tap Install. The deck does not install during a print.
  1. 3Wait while the deck downloads and writes the update. It restarts into the new version.

Back up your data

A backup is one file with your data: the rolls, the print history, the settings, the slicer API keys, the paired phones and the Klipper config. It can also have the G-code files. Make a backup before you change the SD card, and keep it on a computer.

A backup password encrypts the file. Without the password, nobody can open the backup, and the Printdeck cannot restore it. The password cannot be recovered, so keep it safe.

The backup does not have the password of the Printdeck or the Wi-Fi network. A restore keeps the password and the Wi-Fi network of the Printdeck that you restore to.

  1. 1Open http://printdeck.local/system in a browser, and log in with the password of the deck.
  1. 2Under Backup, type a backup password of 8 characters or more two times. Select Include the G-code files to put them in the backup.
  1. 3Click Download the backup. The browser saves a file with the name printdeck-backup-NAME-DATE.pdbk.
  1. 4To restore, open the same page. Under Restore, type the backup password, choose the backup file, then click Restore. Do not restore during a print.
  1. 5The Printdeck checks the whole file before it changes a file, so a wrong password or a damaged file changes no data. After the restore, Klipper and the Printdeck restart.

Try the deck with a simulated printer

The deck can run a simulated printer in place of the real printer. Klipper then runs the config of a real printer on a board in the deck. The board heats, homes, probes and prints in real time, but no motor moves. Use it to learn the deck, or to test a file from the slicer. You need no cable and no printer.

The deck keeps your printer.cfg as printer.cfg.real while the simulated printer is in use. Real printer puts it back with no change. An orange band at the top of each screen shows the simulated printer.

  1. 1Open Machine, then Simulated printer. A new deck with no printer has a Simulated printer key on the setup screen.
  1. 2Tap the printer to simulate, then Simulate. Klipper restarts with the simulated printer.
  1. 3Print as on a real printer: send a file from the slicer, or tap Print a file.
  1. 4To stop the simulation, open Machine, then Simulated printer, and tap Real printer, then Go back. Klipper restarts with your printer.cfg.

  1. 2After a stop or a power cut of the printer, tap Firmware restart.
