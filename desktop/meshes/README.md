# The meshes of the 3D window

The printer meshes come from the CAD of the LulzBot TAZ Workhorse ("Redgum"):
https://gitlab.com/lulzbot3d/printers/redgum

The CAD is by LulzBot. It has the licenses
"GPLv3 or later and/or CC BY-SA 4.0". These meshes have the same licenses.

cad/export.py makes the meshes from the FreeCAD files of the CAD. The file has the steps.

The deck_*.bin meshes are the Printdeck mount of this repository (lulzbot/). cad/deck.py makes
them from the meshes of lulzbot/make.sh. They have the license of this repository.
